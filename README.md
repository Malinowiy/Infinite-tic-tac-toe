# Крестики-нолики на бесконечном поле

Десктопное приложение на Python + Tkinter: поле не ограничено рамками —
ходите куда угодно, двигайте поле мышью и меняйте масштаб колесом.
ИИ выбирает ход, максимизируя взвешенную «силу хода»: собственная угроза
против угрозы соперника (то есть блокировки).

## Запуск

```bash
cd infinite-tic-tac-toe
python3.14 main.py
```

Проверено на Python 3.14.8 + Tk 9.1 (пакет `python-tk@3.14` из Homebrew)
и на системном Python 3.9.6 + Tk 8.5 (`/usr/bin/python3 main.py`).
Внешних зависимостей нет — только стандартная библиотека.

Тесты:

```bash
python3.14 -m unittest discover -v
```

## Управление

| Действие | Как |
| --- | --- |
| Поставить знак | клик по пустой клетке |
| Сдвинуть поле | перетаскивание левой/правой/средней кнопкой мыши |
| Масштаб | колесо мыши, `+` / `-` (масштаб идёт вокруг курсора) |
| Сдвиг с клавиатуры | стрелки `← ↑ → ↓` |
| Центрировать поле | кнопка «В центр» или клавиша `C` |
| Показать силу ходов | кнопка/флажок или клавиша `E` |
| Новая игра | кнопка или клавиша `N` |
| Отменить ход | кнопка или клавиша `U` |
| Пауза автопартии | кнопка «Пауза (ИИ–ИИ)» (в режиме ИИ–ИИ) |

Клавиши работают, когда фокус на доске (достаточно один раз щёлкнуть по ней).

## Настройки

* **Режим** — «Человек – человек», «Человек – ИИ», «ИИ – ИИ» (автопартия).
* **ИИ играет за** — `X` (ИИ ходит первым) или `O`.
* **Сложность ИИ** — Лёгкая / Обычная / Сложная (см. ниже).
* **Знаков в линии** — 3…8, по умолчанию 5 (как в гомоку).
* **Лимит ходов** — 0 = без лимита; иначе при достижении лимита объявляется ничья
  (на бесконечном поле ничья иначе почти недостижима).
* **Показывать силу ходов** — оверлей: клетки подсвечиваются тем ярче,
  чем выгоднее туда сходить (число — оценка хода).

Правила (длина линии, лимит ходов) применяются при старте новой игры.

## Как работает ИИ

Для каждой клетки-кандидата (пустые клетки в радиусе `R` по Чебышёву от
уже поставленных знаков) считается оценка:

```
score = ATTACK · my + DEFENSE · opp + ε · centrality
```

* `my` — сила линии, которую в этой клетке построит ИИ;
* `opp` — сила линии, которую в этой клетке построил бы соперник
  (это и есть ценность блокировки);
* `ATTACK = 1.0`, `DEFENSE = 0.9` — свою угрозу ценим чуть выше чужой;
* `ε · centrality` — микро-бонус за близость к своим знакам,
  нужен только чтобы детерминированно снимать ничьи в оценках.

Сила линии считается по **всем окнам** длиной `win_len`, которые содержат
клетку, по четырём осям (горизонталь, вертикаль, две диагонали):

* если в окне есть знак соперника — окно бесполезно;
* иначе `potential` = сколько знаков игрока окажется в окне после хода,
  `empties` = сколько в окне пустых клеток;
* `potential == win_len` → мгновенная победа, оценка `WIN_SCORE = 10^9`;
* иначе `score = POTENTIAL_SCORE[potential] · OPEN_WEIGHT[empties]`.

| potential | 2 | 3 | 4 |
| --- | --- | --- | --- |
| вес | 10 | 100 | 10 000 |

| empties | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- |
| множитель | 1.0 | 0.5 | 0.25 | 0.1 | 0.05 |

Оценки четырёх осей **складываются**, поэтому «вилки» (двойные угрозы)
автоматически получают приоритет, а сумма ограничена `WIN_SCORE / 2`,
чтобы никакая комбинация не перебила мгновенную победу.

Победа и блокировка обрабатываются отдельно: ход, выигрывающий немедленно,
получает `WIN_SCORE`; ход, которым соперник выиграл бы, даёт нам
`DEFENSE · WIN_SCORE ≈ 0.9 · 10^9` — этого всегда хватает, чтобы закрыть
чужую линию, если своей победы нет.

### Сложности

| Режим | Радиус кандидатов | Поведение |
| --- | --- | --- |
| Лёгкая | 1 | случайный выбор из пяти лучших ходов (ошибается по-человечески) |
| Обычная | 2 | строго лучший ход по эвристике |
| Сложная | 3 | то же + страховка: ходы, после которых соперник побеждает немедленно, дешевеют в 20 раз |

## Файлы

| Файл | Что внутри |
| --- | --- |
| `game.py` | модель поля: словарь `{(x, y): "X"/"O"}`, победа, ничья, отмена хода, кандидаты |
| `ai.py` | эвристика: оценка клетки, выбор хода, режимы сложности |

| `main.py` | точка входа |
| `tests/` | `test_game.py`, `test_ai.py`, `test_ui.py` (UI-тесты пропускаются без Tk) |

## Тесты

54 теста, запуск — `python3.14 -m unittest discover -v`.
Проверяются: победа/ничья/отмена хода на любых координатах (включая
отрицательные и очень большие), подсчёт кандидатов, порядок оценок линий,
выбор мгновенной победы, блокировка, «вилка», поведение сложностей,
а также интерфейс: перевод «экран ↔ клетка», зум/панорама, клики,
ответ ИИ, откат хода, оверлей и отрисовка выигрышной линии.

Одна из проверок — свойство: против случайного игрока ИИ (линия 3)
не проигрывает ни в одной из 12 партий с фиксированными генераторами.
